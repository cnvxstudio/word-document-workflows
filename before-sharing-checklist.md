# Before sharing a Word document

## Content

- [ ] Replace every bracketed prompt and remove drafting instructions.
- [ ] Check names, dates, totals, and document version.
- [ ] Make the title describe the actual document.
- [ ] Check that every action has an owner and a due date where needed.

## Structure and layout

- [ ] Keep heading levels in order.
- [ ] Use real lists rather than manually typed bullet characters.
- [ ] Check table widths, image placement, and page breaks.
- [ ] For a merged file, confirm that the report comes before its appendix.
- [ ] Review the combined file's headers and footers.

## Delivery

- [ ] Download the final file with a clear name.
- [ ] Open the downloaded file to confirm that it contains the intended edits.
- [ ] Use DOCX when the recipient needs to edit it; use PDF for a fixed-layout copy.
- [ ] Check that links lead to the intended destination.
- [ ] Remove information that the recipient does not need.
- [ ] Keep the source files until the final copy has been accepted.
