# Practical Word document workflows

A small, reusable guide for editing a document, combining a report with an appendix, and checking the result before sharing. Includes a meeting-notes template and a final review checklist. The examples contain no personal or customer information.

## Start with a clean copy

Keep the original file and work on a copy. Give the copy a descriptive name, such as `project-notes-reviewed.docx`. If several people supplied files, decide their order before combining them.

## Edit a short document in your browser

1. Open [WordOnline](https://wordonline.io/) and choose one local DOCX file. You can also start with a blank document or a built-in template.
2. Update the heading and body text. Use heading styles for section titles and a real numbered list for ordered steps.
3. Review tables and images, especially after changing the surrounding text.
4. Download the edited document as DOCX. Download a PDF when you need a fixed-layout copy for sharing.
5. Open the downloaded file and check its contents before sending it to someone else.

WordOnline requires no account for these tasks and processes document content in the browser. Its interface is in English. Editing is unlimited; the free processing allowance is 10 successful tasks per browser per local day, with a 25 MB limit per file. Download the result to keep your changes.

## Combine a report and an appendix

1. Keep the report and appendix as separate source files.
2. Open the [document merger](https://wordonline.io/merge-word/) and select both files.
3. Put the main report first and the appendix second. Use the reorder arrows to correct the order before merging.
4. Choose DOCX for further editing or PDF for a fixed-layout copy.
5. Merge and download the result. Check the section order, page breaks, tables, and images.

The merger accepts up to 20 files per merge, each no larger than 25 MB. Each input starts on a new page; the first document supplies the Word headers and footers.

## Use the included templates

- [Meeting notes](meeting-notes-template.md): copy the structure into your editor and replace the bracketed prompts.
- [Before-sharing checklist](before-sharing-checklist.md): use it after editing, merging, or exporting a document.

These are editable text templates. They do not need an account or a particular editor to be useful.
